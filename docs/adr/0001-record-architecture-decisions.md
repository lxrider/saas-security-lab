# ADR-0001: Record architecture decisions

## Status

Accepted

## Context

RedRocket will evolve step by step.

Some decisions will change the architecture and may also change the security
problems we need to understand.

It should be possible to remember why those decisions were made.

## Decision

Important architecture decisions will be recorded in `docs/adr/`.

Each ADR should stay short and explain:

- the context
- the decision
- the main consequences

Only decisions that meaningfully affect the architecture or security of
RedRocket need an ADR.

## Consequences

Important choices remain understandable as the project evolves.

The documentation stays lightweight.
